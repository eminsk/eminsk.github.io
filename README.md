## Featured Libraries & Systems

1. **[pureapk (pyapk)](https://github.com/eminsk/pyapk)** — Zero-dependency pure Python Android APK engine with Android 15 16KB ELF page alignment (tag `0xd935`), APK v1/v2/v3 signatures, multi-store packaging (AAB, IPA, MSIX), and APK patching without Java or Android Studio.
2. **[pyfasm / pyfasm64](https://github.com/eminsk/pyfasm)** — Universal Native No-GIL (3.13t-3.16t) & PyPy to pure x86_64 FASM AOT Compiler (~9KB standalone binaries, zero runtime overhead).
3. **[agentjit](https://github.com/eminsk/agentjit)** — Just-in-Time Compiler for AI Agent Trajectories (compiles 30s LLM roundtrips to 0.08ms Python code with 0 tokens, Native MCP Server).
4. **[nanovector](https://github.com/eminsk/nanovector)** — The SQLite of Vector Search & Episodic Memory for AI Agents in ~120KB (AVX2+FMA, ARM NEON, C99/FASM, Native MCP Server).
5. **[nanogemm](https://github.com/eminsk/nanogemm)** — Minimalist, bare-metal SIMD & Assembly GEMM engine for Python (up to 2.8x faster than NumPy on CPU, Native MCP Server).
6. **[nanorecall](https://github.com/eminsk/nanorecall)** — 100% Private, Zero-Cloud Desktop Memory & Screen Search Engine in <200KB.
7. **[yfinance-ta-patterns](https://github.com/eminsk/yfinance-ta-patterns)** — Institutional candlestick pattern scanner (61 TA-Lib patterns), unbiased backtester, AI Confluence Scorer, Native MCP Server.
8. **[xlsx-viewer-pro](https://github.com/eminsk/xlsx_vievers)** — Headless Excel formula engine (129+ functions), SSE2 SIMD, Chart Wizard, Native MCP Server.
9. **[avito-sdk (Avito SDK Pro v0.4.4)](https://github.com/eminsk/avito-sdk)** — Standalone Windows Desktop GUI (`~28MB .exe`) & pure HTTP/Chrome TLS (`curl_cffi`) Avito scraping SDK with price-drop tracking, `spfa.pro`, Telegram proxy isolation, CLI, and Native MCP Server (`avito-mcp`).
10. **[parser_avito (Avito Parser v3.2.29)](https://github.com/eminsk/parser_avito)** — Maintained Flet Desktop GUI parser for Avito featuring Playwright Chromium browser login and anti-bot fallback.
11. **[wb-sdk-pro (WB SDK Pro v2.5.0)](https://github.com/eminsk/wildberries_parser)** — All-in-One Wildberries Sync/Async SDK, Interactive Telegram Bot (`WBTelegramBot`), Standalone Windows `.exe` GUI (`WBSDK_Pro.exe`), WB Wallet calculator, Search Rank Tracker, Smart Review Analyzer + Hybrid Free/Paid AI Engine (`g4f`, `Ollama`, `OpenAI`, `DeepSeek`, `OpenRouter`, `ProxyAPI`, `Groq`), 13-command CLI (`wb-parser`/`wb-sdk`), 9-tool MCP Server (`wb-mcp`), MobileProxy rotation, and APT PPA supporting Python 3.8–3.16, PyPy 3.8–3.12 & No-GIL.
12. **[ozon-sdk-pro (Ozon SDK Pro v1.2.0)](https://github.com/eminsk/ozon_parser)** — All-in-One Ozon Sync/Async SDK (Composer API widgets, Seller INN lookup, Ozon Card savings, Search Rank Tracker, Smart Review Analyzer + Hybrid Free/Paid AI Engine `g4f`/Ollama/OpenAI/DeepSeek/OpenRouter/ProxyAPI/Groq/Gemini), Interactive Telegram Bot (`OzonTelegramBot`), 14-command CLI (`ozon-parser`/`ozon-sdk`), 9-tool MCP Server (`ozon-mcp`), Standalone Windows `.exe` GUI (`OzonSDK_Pro.exe`), MobileProxy rotation, Debian APT PPA (`python3-ozon-sdk-pro`), and `conda-forge` recipe supporting Python 3.8–3.16, PyPy 3.8–3.12 & No-GIL.
13. **[screenvideo](https://github.com/eminsk/screenvideo)** — Desktop screen recorder with WASAPI loopback audio, real-time H.264 streaming, Native MCP Server, and pure x64 FASM native edition.
14. **[fasm-modern-sdk](https://github.com/eminsk/fasm-modern-sdk)** — Modernized SDK and header toolchain for Flat Assembler (FASM v1.73 / FASMG).
15. **[ppa](https://github.com/eminsk/ppa)** — Official APT Repository for Debian and Ubuntu Linux.
