pureapk (pyapk)

Zero-Dependency Android 15 APK Engine & Signer

Pure Python engine for building, modifying, repacking, and signing Android APKs without Java, Android Studio, or SDK. Includes full Android 15 16KB ELF page alignment (tag 0xd935), v1/v2/v3 signatures, and multi-store packaging.

  • 16KB Page Alignment for Android 15 (API 35+ Google Play compliance)
  • Zero JVM, zero Android SDK/NDK, zero native tool requirements
  • Multi-Store packager: APK, Google Play AAB, iOS IPA stub, Windows 11 MSIX
  • In-place APK modification, wheel extraction, and release-ready signing

pyfasm / pyfasm64

Universal Python AST to x86_64 FASM AOT Compiler

Translates Python AST directly into self-contained standalone PE+ (.exe, .dll), ELF64, and Mach-O binaries (~9KB). Zero virtual machine, zero Python runtime overhead. True multi-threaded concurrency (CreateThread).

  • Produces pure 9KB native binaries without Python DLL or interpreter
  • Supports Python 3.8–3.16, Free-Threaded No-GIL (3.13t-3.16t) & PyPy
  • True hardware multi-core parallelism with lock-free atomic primitives
  • SIMD JSON parser and native Win32/GDI assembly GUI engine
